# Neon Superpowers

A one-off, open-source hackathon showcase for a local-first personal agent, derived from Superpowers.

## Status

This repository is an initial scaffold. It contains project documentation and a license; no application source has been imported yet. The application import will be reviewed separately before publication.

## Planned direction

- A local-first personal-agent experience.
- Agent-to-interface interactions using AG-UI and Assistant UI.
- Sponsor integrations for the hackathon, added as separate reviewed changes.

These are planned capabilities, not features available in this scaffold. Setup and demo instructions will follow the application import.
